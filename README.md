# PlacePilot AI

An AI-powered placement preparation platform built with React, TypeScript, Vite, Express, and Google Gemini.

## Features

- Student dashboard and placement-readiness overview
- Coding practice
- Aptitude practice
- Resume builder
- Interview preparation
- Placement/company information
- Study planner and habit tracking
- Academic mentor section
- Analytics and leaderboard views
- AI chat assistant and AI-powered features
- Activity History with persistent server-side demo data
- Student and Admin demo flows

## Technology Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS, Recharts, Lucide React, Motion

**Backend:** Node.js, Express, TypeScript/TSX

**AI:** Google Gemini API (`@google/genai`)

**Documents:** jsPDF and Mammoth

## Requirements

- Node.js 18.18 or newer
- npm
- A Google Gemini API key for AI features

## Installation and Run in VS Code

1. Extract the project ZIP.
2. Open the extracted **PlacePilot_AI** folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Install dependencies:

```bash
npm install
```

5. Create a file named `.env` in the project root.
6. Add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

7. Start the application:

```bash
npm run dev
```

8. Open:

```text
http://localhost:3000
```

## Useful Commands

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm start        # Start production server after building
npm run lint     # TypeScript check
npm run clean    # Remove the dist folder
```

## Submission Notes

- `node_modules` is intentionally not included. Run `npm install` after extracting the project.
- `.env` is intentionally not included. Create it locally and keep the API key private.
- `dist` is generated by the build command and is not required in the source submission.
- `db.json` is runtime data and is intentionally excluded from source control.
